## NNGreyscale

Это мой первый шаг в направлении области искусственного интеллекта.
Основная задача этого проекта, познакомится с фреймворком PyTorch.

Функционал этого проекта прост:
- Модуль torch_file.py - задает структуру нейронной сети;
- Модуль model_training_module.py - обучает нейросеть;
- Модуль image_module.py - создает изображение из пикселей имеющих случайный цвет;
- Модуль data_processing_module.py - позволяет получать данные из сгенерированного нами изображения и преобразовывать их к нужному виду;
